# 증거와 검증 범위

## 과거 실제 기록에서 확인한 것

| 범위 | 확인 | 미확인 |
|---|---|---|
| 최초 ADC/배터리 | 컨트롤러2대 기록100%, 일반 부팅·짧은 입력·사용자의 셋톱 홈 확인 | 전체 readback, 장기 꺼짐 해결 |
| 첫2ms | 한 세트 기록, 주기 바이트2·수신기Full-Speed IN2 확인 |500Hz 새 입력, 절대 지연 |
| 최종 enhanced | 한 대 앱105472바이트 전체 일치, 뒤512바이트FF, 정상2.4G 물리 입력15초 | 다른 한 대 적용, 두 세트 장기 게임 |
| 자동 계측 | 실제 컨트롤러 태그를 실제 수신기→Windows에서 관측 | 물리 버튼 접점 시점, source/PC clock 동기화 |

자동 계측 임시 코드는 최종 일반 이미지에 없으며 이 저장소는 진단 이미지를 배포하지 않는다.
최종 앱 전체 읽기 일치는 [집계 기록](../evidence/final-readback-verification.json)에 보존했다.
개인 장치 전체 덤프·일련번호·키는 공개하지 않아 타인이 원시 장치 덤프에서 재감사할 수 있는 자료와는 범위가 다르다.

## 자동 계측 해석

순번은 송신 처리 경로에 넣은 source 태그이며 전파 ACK 카운터가 아니다.
앞선 유효 구간은11385개 관측/11384 source 증가/46.51377초,
후속은15724개 관측/15729 source 증가/54.4104279초다.
source tick 추정은 각각1.991342/1.991232ms였다.

PC 조회 자체에도 최대 약5.314ms 공백이 있어 후속6개 번호 공백이 RF·USB·드라이버·API 병합 중 어디서 발생했는지 알 수 없다.
source/PC clock을 동기화하지 않아 tick과 PC 시각을 빼서 단방향 지연ms를 구하지 않는다.
단순 manual joystick 변화율과 합쳐 물리500Hz/버튼 반응속도 검증이라고 부르지 않는다.
전후 두 순차 실행의 생성률 차이는18.115%이나 반복 무작위 A/B가 아니다. 순정과의 비교도 아니다.

## 명령어 검사

과거 실제 Thumb 바이트 부분 실행(주변장치 호출은 hook):

- 최초 ADC9240개, 배터리 상태1536개, 연속 시나리오4개.
- 첫2ms 계산320개.
- 첫 통합 일정/활동1373개, 물리 스위치 조건 수정1080개.

[공개 테스트](../tests/)는 정확한 원본으로 이미지를 만들고 실제 Thumb 부분 실행을 재현한다.
ADC 모든 초기 실패 byte·채널·정상 샘플 위치 및 배터리 상태를 검사하고,
일정은 다양한 스위치·period·tick·작업시간 조합을 검사한다.
비정상 원본·preimage·중첩 CRC 오류는 거부해야 한다. 외부 작업/queue는 hook이므로 전체 MCU·RF 시뮬레이션이 아니다.
ARM 명령·주변장치·정착 시간·실제 전압을 모두 검증한 것으로 확대하지 않는다.

## 공개 배포 검사

- 공식 서버의 원본을 새로 내려받아 고정 SHA-256 확인.
- 세 컨트롤러 변형·수신기 패치·공식 원복 두 파일을 기존 실제 기록 파일과 같은 해시로 생성.
- 생성된 최종 코드와 직접 작성한 assembler 소스 일치 확인.
- 수신기의 중첩 CRC/다른 파일 보존·컨트롤러 재암호화 roundtrip 확인.
- 원본 bit flip·수정본을 원본으로 재사용·preimage 불일치·겹침·범위 초과·실행 어댑터의 알 수 없는 이미지 거부 검사.
- Windows 배포 바이너리 빌드 및 신규 폴더에서 생성 경로 검사. DLL 해시·로드만 확인하는 모드와 이미지 검사 모드는 장치를 만지지 않는다.
- 공개 어댑터로 장치를 다시 플래시하는 실물 시험은 하지 않았다. 수신기 독립 identity preflight의 실제 응답 호환성도 새 wrapper에서는 미검증이다. 불일치 시 중단하며 우회하지 않는다.

## 남은 항목

실제 버튼 접점→PC/게임 지연, 장기간 재현 조건, 전압/충전 상태, CPU/RF 부하,
두 세트 동시 사용, 진동/터보, Bluetooth·2.4G·유선 각각의 절전/재접속과 배터리 지속시간.
기존 전원 꺼짐의 원인이 이 코드였다는 인과관계는 아직 확인하지 못했다.
